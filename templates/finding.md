# Finding and verification record

Use one record per distinct control gap. Refer to evidence by ID and keep the
actual artifacts in approved storage.

| Field | Record |
| --- | --- |
| Finding ID, title, and scope record | |
| Affected component, environment, and revision | |
| Expected control and source of requirement | |
| Observed state and evidence IDs | |
| Potential impact, exposure assumptions, and coverage gaps | |
| Priority, confidence, and rationale | |
| Remediation decision, accountable owner, and target date | |
| Acceptance criteria and required artifact sources | |
| Verification date, reviewer, revision, evidence IDs, and result | |
| Disposition, next review date, and residual risk | |
| Risk acceptance approver and expiry, if applicable | |

For each evidence ID, record source type, environment, revision, observation time,
and handling label. Apply the [triage and verification guide](../notes/triage-and-verification.md)
when deciding whether the evidence supports closure.
